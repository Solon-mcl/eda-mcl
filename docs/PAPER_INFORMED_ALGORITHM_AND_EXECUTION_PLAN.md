# 论文启发的通用覆盖率驱动激励算法与执行规划

> 状态：设计报告，尚未实现或验证。依据为赛题原文、现有仓库与两篇用户提供的 PDF。本文的算法选择是建议，不把论文中的设计或论文作者的要求当成赛题指令。

## 一、结论先行

建议将主线改为 **Coverage Dependency Graph（覆盖依赖图，CDG）+ 合法事务模板 + 自适应输入偏置 + 预算感知搜索**。这条主线无需先训练大型模型，能直接利用赛题给出的 spec、covergroup 和逐周期 bin 掩码，符合当前正收益样本极少的现实。LLM 用于低频的规格语义解析与停滞时提出可检验假设；训练模型首先做候选事务排序。自回归程序生成和离线 RL 暂列研究分支，仅在跨结构留出实验显示净增益时进入提交版。

与上一版规划相比，新增的关键不是再加一种宏，而是让系统知道：**哪个未覆盖 bin 可能受哪些合法输入字段、取值、组合和时间顺序影响**；然后用执行反馈不断修正这一关系的可信度。

## 二、两篇论文到底提供了什么

### 1. Nazi 等，《Adaptive Test Generation for Fast Functional Coverage Closure》

- 论文方法 `CDG4CDG`：解析 covergroup 和测试平台，构建 `coverbin → coveritem → random variable/value` 的依赖图；对未命中的 coveritem 累加对应输入值的权重，归一化后作为 constrained-random verification 的采样分布（第 3–5 页，图 3–5、算法 1）。这是**无需大规模离线训练即可获得可解释搜索先验**的主要启发。
- 其 `θ_i = w_i / Σw` 是在给定未命中 coveritem 计数、多项分布假设下的最大似然解（第 5 页），**不是对任意 DUT 的全局最优覆盖策略的证明**。它没有解决隐藏状态、长时序、联合约束或不可达 bin 的一般问题。
- 实验在 RISC-V Ibex 与 TPU 模块上，用 Veriﬁc 解析、VCS 仿真；按一次次完整仿真运行调整随机变量分布，五个随机种子。三个工业模块的完整覆盖达到时间在论文中分别为 66、23、63 次迭代；对照在 340、超过 500、超过 500 次迭代，得到至少 5.15×、21.7×、7.9× 的闭合速度改善（第 6–7 页、表 II）。这些是**论文环境的多轮回归结果**，不能当成本赛题逐周期成绩。
- 论文明确指出：只能追溯到随机变量的 coverpoint 才能如此优化；无法映射者退回随机激励（第 1、4 页）。分桶过粗丧失定位能力，过细可能与已有约束冲突，图 9 展示了非单调效果（第 7 页）。

### 2. Kumar 等，《AI – accelerating coverage closure using intelligent stimulus generation》

- 论文在 Cadence Xcelium SimAI 的 `input-bias` 工作流中，从发起端、可达目标、操作类型和协议约束生成合法的覆盖组合及偏置文件；依据回归结果提高未覆盖交叉组合所需输入的权重（第 2–5 页）。对本题最有用的是**先排除不合法组合，再针对 cross bin 联合选参**，而不是使用该商用工具本身。
- 论文强调偏置应较早介入：其图 6–7 比较不同基线回归阶段启用偏置，越早启用有更大收益（第 6–7 页）。这与赛题 AUC 占 40% 一致：不能等到最后几千 cycles 才开始分析覆盖缺口。
- 报告中的一个约 60 万 bin 的移动平台互连案例，正常回归约 8.4 千仿真小时达到约 98%，偏置方案约 3.8 千小时达到 100%；表 II 还给出不同起点的 >54%、>56% 时间缩短（第 6 页）。摘要和结论用“至少/约 30%”作总体表述；本文只把数字当作案例，不推断本题效果。其流程依赖随机化数据、UVM/SimAI 回归数据库和每轮模型更新，而本题在线阶段不能改模型权重。

| 论文元素 | 本题可用的改写 | 不直接移植的原因 |
|---|---|---|
| CDG4CDG 的覆盖依赖图 | 从 spec、covergroup 和可用 metadata 构建带可信度的 `bin ↔ 字段/参数/事务` 图 | 评测不保证提供 RTL、UVM 随机变量、coveritem 命中统计或内部信号。 |
| 未覆盖项加权采样 | 给合法候选字段值/事务组合添加偏置与探索下限 | 只有**累计二值 bin**；不能假装看到了 bin 内各条件的命中情况。 |
| input-bias 的合法组合表 | 构建约束域与交叉目标的联合候选生成器 | 赛题 `predict()` 输出动作向量，不调用 SimAI/Xcelium 的约束求解器。 |
| 迭代回归学习 | 在线更新计数、区间和候选分数；模型参数保持只读 | 赛题禁止推理时更新模型权重。 |
| 提早介入偏置 | 初始化即规划易覆盖和长序列任务，按预估增益分配前期预算 | 本题按周期计 AUC，论文按回归轮次/仿真小时计。 |

## 三、新算法：证据化覆盖依赖图与事务搜索

### 3.1 可见信息与图结构

评测期保证输入是两个路径 `dut_spec_path`、`covergroup_path` 与每周期的 `(coverage_state, step, max_steps)`。`coverage_meta.json` 可探测但不得假定总存在；未找到或 bin 顺序校验失败时，仅使用可确认的 covergroup 解析结果，必要时退回总覆盖反馈。不得使用公开 RTL 的内部状态作为隐藏 DUT 运行时输入。

为每个目标 bin 建立以下节点和边：

```text
bin B ← sample expression / cross terms / iff / sequence
      ← spec 中的可控字段或输入角色
      ← 值域、枚举、前置事务、保持周期和复位条件
```

边标注 `direct`（spec/covergroup 明确给出）、`inferred`（规则或 LLM 猜测）、`empirical`（重放验证）、`unknown`。只有 `direct` 和经校验的 `empirical` 能作为强约束；`inferred` 只引导探索。对从 DUT 内部派生的 `result_ok`、窗口完成等 bin，不宣称知道内部条件，而是先关联“完成有效事务”及可能的参数簇，靠反馈辨别。图不能覆盖的 bin 保留随机/模板探索分支。

对于简单枚举或边界 bin，建立单字段候选；对于 cross，生成**联合元组**并验证合法性；对于 sequential，生成有前置步骤和最短保持长度的程序。不能把 cross 的各字段独立加权后就认为联合目标会被触发。未知隐藏阈值用分层扫描，不将猜测值写入固定规则。

### 3.2 候选生成器

基础原语统一为 `reset/recover`、`configure`、`pulse/request`、`hold/advance`、`ordered sequence`、`fault/retry`。每个模板声明：字段角色、合法域、前置关系、持续时间候选、可中断点、预计目标 bin、最大成本。执行器把模板编译为 `float32` 动作队列，逐周期出队；无论候选来自规则、LLM 还是模型，都走相同的合法性检查。

数值域先采用 `{最小、最大、0、1、枚举、规范特殊值、对数间隔、局部邻域}`；时序长度采用几何候选加命中邻域细化。交叉参数按合法元组、覆盖状态与尝试历史采样，保持非零探索概率。候选失败时先更换参数或延长窗口，超过可解释的失败预算才 reset，避免长序列反复被截断。

`float32` 对所有超过 `2^24` 的整数不保证精确表示；若 spec 要求精确高位 token/key，必须按官方动作解码规则确认是否分段编码，否则标记该目标“接口表示风险”，不能误判搜索器失败。

### 3.3 在线偏置与调度

每个可执行候选 `q` 存储试验次数、用时、真正新增的 bin 集合、最近收益和参数配置。对未覆盖 bin `b` 的每条可信依赖边给予先验权重；来自论文一的直观起点是“一个输入取值关联多少个仍未覆盖目标”，但实际用平滑与探索混合：

```text
prior(q) = Σ_{b missing} confidence(b,q) × feasible(b,q)
P(q) = ε·U(q) + (1-ε)·softmax[prior(q) + empirical_gain(q) - cost(q)]_q
```

公式只是实现起点，需用消融定参数。`empirical_gain` 以**事务结束前后**的新增 bin 计算，并记录单位周期收益及 bin 首次命中时间；长时序无中间覆盖不立即记为失败。候选选择结合早期 AUC 收益与最终闭合：先做低成本高命中率的事务，同时为长序列和难 cross 预留启动机会，随后将预算更多转向剩余 bin。保留固定比例探索，防止错误依赖图永久排除正确方案。偏置不能把所有已覆盖相关值权重设为 0：这些值可能是到达未覆盖状态的前置步骤，论文一也观察到约束冲突会令分布权重失效。

允许在线更新的是统计、候选队列和规划状态，不更新权重文件或神经网络参数。每个宏完成后，以 `coverage_after & ~coverage_before` 记实际新增 bin；不把同一程序内的每一拍都错误视作独立样本。程序信用通过重放、删除、缩短、参数扰动确认，不能仅用固定三步延迟系数充当因果证据。

### 3.4 LLM 与小模型的分工

LLM 在初始化时生成**可验证的语义草案**：字段角色与范围、事务前置、可能的 bin 关联、cross 联合条件、候选参数簇、所依据的 spec/covergroup 片段和不确定项。解析器检查来源片段、动作维度、数值范围和时间依赖；未验证内容作为低权重候选，不直接执行。可选停滞重规划仅传缺失目标、已试验参数摘要和剩余预算，要求输出新的可证伪试验，不要求预测内部真实状态。设置每 DUT 调用数/Token/墙钟上限和失败降级；按无 LLM、初始化 LLM、初始化+重规划三组消融决定默认配置。

当前 `deepseek_planner.py` 已能在 `__init__()` 一次调用并降级，但返回原始动作数组，尚未做上述完整的语义/约束验证；其 `family_hint` 不应参与新方案的 DUT 路由。若最终启用 API，提交报告必须更新模型名、版本、端点、耗时与 Token。每周期 `predict()` 保持本地轻量。

离线模型先预测 `(IR, 目标, 候选程序, 历史) → 成功率或单位周期新增 bin`，只作候选排序先验。现有训练数据 5108 条仅 10 条正收益，不足以可靠训练程序解码器或 IQL；先提高成功事务的数量、结构多样性和重放质量。神经模型仅在跨结构留出、同墙钟和同周期预算的配对实验中稳定优于无模型 CDG 基线时部署。

## 四、落地执行规划

| 阶段 | 任务与产物 | 验收与停损 |
|---|---|---|
| M0：版本与接口 | 核对赛题原文 AES/SPI/温控和仓库 DMA/SPI/SPI 的差异；核对 metadata 路径、bin 顺序、动作解码与隐藏参数；冻结实验快照。 | 能在原样官方发布包上实例化并返回合法 `float32` 向量；未知条件单独记录。 |
| M1：统一基线 | 同一 runner 比较纯随机、组委会贪心、当前通用策略、旧专家、无学习事务模板；计算每 1000 cycles 采样 AUC、终值与总墙钟。 | 至少三个种子；不同后端与版本的结果不混表。旧专家只是本地性能上界，不作为通用提交路径。 |
| M2：依赖图 | 解析 coverpoint/bin/cross/iff/sequence 与 spec 字段，建立来源与可信度；缺失 metadata 和解析失败安全降级。 | 对公开 DUT 人工抽查图边、bin 对齐；不得依赖内部派生信号原值。 |
| M3：合法搜索 | 实现联合参数候选、分桶偏置、长窗口扫描、事务重放与停滞恢复；加入探索下限和 AUC 调度。 | 相同快照下本地公开集对当前通用策略的终值和 AUC均改善；长事务可复现。 |
| M4：LLM 试验 | 语义 JSON、来源校验、API 限额/超时/降级；三组消融。 | 仅在未见结构上有稳定净增益、且三 DUT 全程墙钟有余量时默认开启。 |
| M5：学习试验 | 收集完整正负事务及行为概率；结构家族分割；训练候选排序器。 | 对无模型 M3 在留出家族配对实验中终值和 AUC至少不退化，才打包权重；否则维持 M3。 |
| M6：提交 | 标准镜像、覆盖曲线、至少三种消融、LLM 使用报告、README。 | P99 `predict()` 低于建议预算并留仿真余量；API 拒绝/断网可完成；推理不修改模型权重。 |

### 最小消融矩阵

固定种子、DUT、后端、cycles 和总墙钟后比较：`A` 合法模板均匀采样；`B` A + 依赖图偏置；`C` B + cross 联合约束；`D` C + 时间窗口/事务信用；`E` D + LLM 初始化；`F` E + 停滞重规划；`G` D + 学习排序器。主要指标为官方终值覆盖率、1000-cycle AUC、各类 bin 首次命中周期、无效/越界动作率、API 用量与三 DUT 墙钟。若某阶段对跨结构留出没有增益，停在上一版本，不因论文宣传数字继续增加复杂度。

## 五、风险与解释界限

1. **依赖图不完整。** 论文一可回溯 UVM 变量和 coveritem；本题未必可以。图必须带 `unknown` 边和随机探索下限，不允许“未映射 = 不可达”。
2. **联合与时序被边缘分布掩盖。** SPI、温控等需要完整事务、隐藏窗口和正确结果；单字段分布调权不能替代程序与持续时间搜索。
3. **在线学习的边界。** 论文二的每轮模型更新不适合赛题推理约束。统计自适应可以，权重文件和神经参数必须冻结。
4. **论文速度数字不可外推。** 论文一按多次完整回归迭代比较，论文二按数千仿真小时与大型 SoC 比较；本题按 5–10 万逐周期动作、三个隐藏 DUT、终值+AUC评分。
5. **公开数据来源不同。** 仓库现有结果与赛题原文列出的公开 DUT 不一致；先解决发布包版本问题再设覆盖率目标。不能以现有 SPI/DMA 的 100% 推断官方 AES/温控或隐藏 DUT 的结果。

## 六、最终选择

提交候选默认选择 **M3 的无 LLM、无在线训练的 CDG 事务搜索器**作为可靠基线。LLM 与排序器作为可切换增强层，按 M4/M5 的配对消融结果启用。这个顺序直接吸收两篇论文中最可迁移的“依赖关系 + 合法输入偏置 + 早期闭环”，同时对本题独有的长时序、二值反馈、动作接口和在线权重限制给出专门处理。
