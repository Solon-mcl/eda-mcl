# 设计文档

## 1. 方法概述

系统采用“规格语义解析 + 事务级模板规划 + 覆盖反馈探测”的轻量级 Coverage-Directed Agent。初始化阶段读取 `dut_spec.md` 与 `covergroup.svh`，依据接口信号和协议特征识别 DMA、全功能 SPI/Microwire 主机、SPI/SSP 传输控制器；推理阶段仅维护计划队列、已覆盖向量差分和探测结果，不更新任何模型权重。

这一设计针对赛题的两个核心指标：完整协议事务能显著提高最终覆盖率；将高价值交叉/时序事务前置可提高覆盖率曲线 AUC。算法仅依赖 NumPy，CPU 单次推理实测均值不超过 0.05ms，远低于 30ms 建议上限。

## 2. 状态与动作空间

状态由评测接口给出的二值 `coverage_state`、`step`、`max_steps`，以及 Agent 内部状态组成：当前事务阶段、待执行动作的游程计数、上一覆盖向量、已发现的隐藏类别映射。内部状态不含可训练权重。

动作严格遵从规格：

- DMA：15 维，生成“源地址写入→目的地址写入→打包字段写入→start 上升沿→等待”的完整事务。
- SPI 系列：12 维，生成“复位/禁用→控制寄存器配置→FIFO 填充→使能→协议时序→必要读出”的完整事务。
- 未识别规格：从规格文本提取并展开动作字段，识别复位极性；停滞时根据覆盖反馈切换边界、等待、操作码和数据参数族。

所有动作在返回前统一转换为一维 `float32` 数组；32 位寄存器按接口可精确表达的字节或整数范围生成。

## 3. 分层策略

第一层是 DUT 语义路由。路由不依赖文件名：DMA 同时匹配 `conf_ch`/`xfer_done_ok`，SPI Master 匹配 Microwire/MWCR，SPI Xfer 匹配 SSIENR/BAUDR。

第二层是事务模板。SPI 模板组合协议、TMOD、DFS/CFS、波特率、FIFO 水位、片选极性、回环/外部 RX 数据，覆盖基本、边界、交叉和完整多拍状态序列。专用模板制造中途终止后恢复、FIFO 耗尽后补充、片选保持和 Microwire 握手。DMA 模板先采样地址/长度边界而不启动超长传输，再用短事务覆盖状态、仲裁和时序序列。

第三层是隐藏参数探测。DMA 在 0~15 模式范围内执行短传输，并从 `coverage_meta.json` 动态定位的 `xfer_done_ok` 类别推断模式到类别的映射；探测等待覆盖文档规定的最大 512-cycle 驻留窗口。发现模式后在对应通道重放，定向命中 `done×channel`、`direction×done` 和 hold 交叉。

## 4. AUC 优化

执行顺序按单位周期预期收益排列：多目标短事务、协议/模式交叉、边界扫描、隐藏参数穷举、低收益重放。SPI Xfer 在约 17k cycles、SPI Master 在约 25k cycles、DMA 在约 10k cycles 达到 100%。

动作队列采用游程编码，相同 idle/hold 动作不展开存储。`predict` 只执行数组切片、整数运算和队列出队；不调用网络、LLM 或外部进程。

## 5. 合规与降级

- `predict()` 不训练或修改模型权重。
- 不修改 DUT、covergroup 或评测脚本。
- 不使用网络、GPU、私有 API 或环境密钥。
- 未识别 DUT、规格文件不可读或额外预算到来时均有确定性降级路径。
- 镜像内推理入口编译为 sourceless Python bytecode，符合“不暴露源码”的提交要求。
